# VMware Workstation plugin privacy policy

The VMware Workstation plugin is maintained by [mdaneri](https://github.com/mdaneri). It runs as a local Model Context Protocol (MCP) server on your computer and processes data to carry out the VMware Workstation operations you request.

## Information the plugin processes

Depending on the operation, the plugin processes VM names and paths, hardware and network settings, power and snapshot state, guest IP addresses, selected files, logs, and appliance metadata. Guest execution can process program inputs and outputs. Native console screenshots and serial output can contain information displayed or generated by the guest.

The plugin returns tool results to the MCP host you use, such as ChatGPT, Codex, or Claude. The host handles conversation content and tool results under its own privacy policy and settings. Console screenshots, file contents, and guest output can contain sensitive information. The plugin redacts known credentials from supported text outputs, but other sensitive data can remain.

The plugin reads credentials from locally configured files or environment variables when an operation needs them. It supplies them to the relevant VMware service, native utility, or console. Configure credentials locally and keep passwords and tokens out of conversations.

## Network access and sharing

The plugin sends no usage analytics or VM data to the maintainer. It connects to VMware services and guest endpoints as needed for the requested operation. The Workstation REST client uses loopback by default and requires HTTPS for a configured remote origin. Native VNC uses authenticated loopback connections. Serial consoles use local pipes or sockets. Authorized guest programs run inside the VM and can use the guest's own network access.

## Local storage and retention

Credential files, VM files, backups, diagnostic exports, and other operation outputs remain in their configured locations until you or the software managing those files remove them. Background jobs keep bounded, redacted metadata and logs in a private local journal. The journal is capped at 100 records. The plugin prunes completed history older than seven days during job operations, so expired records can remain on disk while the plugin is idle. Journal cleanup does not delete VM files, backups, or exports.

Uninstalling the plugin can leave local files behind, including VMs, credentials, exports, and job records. You manage those files separately. The MCP host manages its own copy of any tool results it receives.

## Support and privacy requests

The maintainer receives information you choose to share in support requests. Use the [project issue tracker](https://github.com/mdaneri/vmware-workstation-mcp/issues) for support and requests about information in a report. Issues are public and GitHub handles them under its own privacy policy. Keep credentials, private VM contents, unredacted diagnostics, and personal information out of public reports. Follow the [private security reporting instructions](SECURITY.md) for suspected vulnerabilities.
